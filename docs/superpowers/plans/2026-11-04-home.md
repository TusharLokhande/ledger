# Home Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/home` placeholder with a one-month summary (Income · Spent · Invested · Savings rate, pace/12-month chart, category donut, recent transactions, add-transaction button), backed by a new `POST api/home` and a new `Investment` account type.

**Architecture:** `HomeService` reuses `IReportService.GetAsync` for every number Reports also shows, and adds only the invested total, a daily cumulative pace series and the 5 most recent transactions. Client gets a new `home` feature that reuses Reports' donut/trend chart and the Transactions form through their `index.ts` barrels.

**Tech Stack:** .NET 10, EF Core + Npgsql, FluentValidation · React 19, Vite, TypeScript, react-query, recharts, shadcn/ui.

**Spec:** `docs/superpowers/specs/2026-11-04-home-design.md`

## Global Constraints

- No test suites in this repo (owner rule). Every task verifies with builds/lint:
  - server: `dotnet build src/server/Ledger.slnx` → `Build succeeded`, 0 errors.
  - client: `cd src/client && npm run build && npm run lint` → no errors.
- Not a git repo: no commit steps.
- `AccountType.Investment = 4`; enum is `short`-backed → **no migration**.
- Home's Income/Spent/usual/categories/12-month trend come from `IReportService.GetAsync` unchanged.
- Client: other features are imported only via their `index.ts`; data flow `api/` → `hooks/` → components/pages.
- Usual window count: 6 (same as `ReportService.UsualWindowCount`). Recent rows: 5.

## Review Focus

1. **Blank database / no transactions** — tiles show ₹0, Savings rate "—", pace line flat at 0 up to today, no usual line, donut and recent show their empty states; nothing throws. (Task 2 Step 6, Task 4 Step 8)
2. **Future month selected** — tiles 0, no Spent or Usual line at all, recent empty; no 500. (Task 2 Step 3 algorithm)
3. **Viewing a 31-day month against shorter earlier months (Feb)** — usual line keeps going flat at that window's month-end total rather than dropping or erroring. (Task 2 Step 3 algorithm)
4. **Income 0 but spending > 0** — Savings rate "—", not `-Infinity%`/`NaN%`. (`savingsRate` already returns null; Task 4 Step 4)
5. **Adding a transaction from Home** — tiles, chart and recent list refresh after the sheet closes. (Task 4 Step 6)

  public record HomePaceDayDto(int Day, decimal? Spent, decimal? Usual);
  public record HomeDto(

      decimal Income, decimal Expenses, decimal? UsualIncome, decimal? UsualExpenses,

- [ ] **Step 1: Request + validator.** `HomeRequestValidator`: `Month` NotEmpty, `AsOf` NotEmpty (auto-registered by `AddValidatorsFromAssembly`).
- [ ] **Step 2: Repository.** `HomeRepository : Repository<Transactions>, IHomeRepository`.
  - `InvestedAsync`: Transfers in `from..to` for the user where `DestinationAccount.AccountType == Investment && Account.AccountType != Investment`; return `(Sum(Amount), distinct DestinationAccountId count)`; `(0, 0)` when none.
  - `RecentAsync`: user's transactions in `from..to`, `OrderByDescending(TransactionDate).ThenByDescending(CreatedAtUtc)`, `Take(take)`, `.Select(TransactionRepository.ToDto)`.
- [ ] **Step 3: `HomeService.GetAsync`.** Deps: `IReportService`, `IReportRepository`, `IHomeRepository`, `ICurrentUserService`.
  ```
  monthStart = first of request.Month; monthEnd = last day of that month
  report = reportService.GetAsync({ From = monthStart, To = monthEnd, AsOf = min(request.AsOf, monthEnd) })
  if !report.IsSuccess → return Result<HomeDto>.Failure(report.Message, report.ErrorStatus)

  started = monthStart <= request.AsOf                        // false for a future month
  spentEnd = min(request.AsOf, monthEnd)
  first = FirstTransactionDateAsync
  windows = started && first != null
      ? ReportWindows.Previous(monthStart, monthEnd, monthEnd, 6).Where(w => w.From >= first)
      : []
  daily = DailyTotalsAsync(user, min(monthStart, windows' From), monthEnd)  — Expense rows only used
  for d in 1..DaysInMonth:
      Spent = started && monthStart.AddDays(d-1) <= spentEnd
              ? sum(expense where monthStart <= Date <= monthStart.AddDays(d-1)) : null
      Usual = windows.Count == 0 ? null
              : round(avg over w of sum(expense where w.From <= Date <= min(w.From.AddDays(d-1), w.To)), 4)
  (invested, accounts) = InvestedAsync(user, monthStart, monthEnd)
  recent = RecentAsync(user, monthStart, monthEnd, 5)
  ```
  Build `HomeDto` copying `From, To, UsualWindows, Income, Expenses, UsualIncome, UsualExpenses, Categories, Months` from `report.Data`.
